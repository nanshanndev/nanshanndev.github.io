nanshann 使用标准 HTML、CSS 和 JavaScript ES Module。你只需要先准备框架发行文件，再用普通 HTTP 服务提供应用。

框架包尚未发布到 npm。以下从源码仓库构建框架；这是发行准备，不是应用模板编译。源码开发要求 Node.js ≥ 22.12。

准备框架

git clone https://github.com/nanshanndev/nanshann.git
cd nanshann
npm ci
npm run build

将整个 dist/ 目录部署在站点 /dist/，保留其中的相对目录结构。不要只复制 index.js。

创建页面入口

在应用目录创建 index.html。import map 需要出现在使用它的模块之前。

<script type="importmap">
  {"imports":{"nanshann":"/dist/index.js"}}
</script>
<script type="module">import 'nanshann';</script>
<ns-include src="./counter.html"></ns-include>

编写第一个组件

在同一目录保存 counter.html。组件的 HTML 声明结构和绑定，CSS 管理样式，顶层 Behavior 创建该实例的状态。

<style>button { color: royalblue; }</style>
<p>\{{ state.count }}</p>
<button type="button" ns-on-click="actions.increment">+1</button>
<script ns-behavior type="module">
  import { createState } from 'nanshann';
  export default function counter() {
    const state = createState({ count: 0 });
    return { state, actions: {
      increment() { state.count++; }
    } };
  }
</script>

在浏览器中运行

通过 HTTP/HTTPS 打开入口，点击按钮，计数会更新。可以先运行仓库已有示例：

npm run dev

再次引用同一份 counter.html，会创建另一个独立的计数器。无需手动 mount，也无需编译应用 HTML。

应用需要 JavaScript、正确的静态资源 MIME 和允许 Blob 模块执行的 CSP。部署细节见 运行与部署。
