组件由一份共享的 HTML、CSS 和可选 Behavior 定义。页面使用组件引用，内部实现留在定义中维护。

两种入口，同一协议

import { createComponent } from 'nanshann';
await createComponent('ui-counter', new URL('./counter.html', import.meta.url));
<ui-counter></ui-counter>
<ns-include src="./counter.html"></ns-include>

标签名与 HTML 地址共用输入、事件、上下文、缓存与生命周期协议。每次引用拥有自己的宿主、ShadowRoot、局部状态与资源。

公开输入与私有状态

import { createState, property, attribute } from 'nanshann';

export default function counter(ctx) {
  const state = createState({ count: 0 });
  return { state, actions: { increment() { state.count++; } } };
}
counter.properties = { label: property('Count', { reflect: true }) };
counter.attributes = { disabled: attribute(false) };

字段声明挂在 Behavior 函数对象上，在调用工厂之前即可读取。property() 接收 JavaScript 值；attribute() 提供字符串、布尔值或有限数字的转换。reflect 连接两侧入口，默认关闭。

模板用 properties.label、attributes.disabled 读取输入；Behavior 中通过 ctx.properties.label.get() 读取。外部对象按引用传入，组件只读消费，需要编辑时自行创建草稿。

事件与内容组合

通过原生 CustomEvent 输出交互。需要跨 Shadow DOM 冒泡时，设置 bubbles: true 与 composed: true。原生 slot 接收调用方内容，保留调用方的绑定与资源归属。

宿主公开动作

const host = document.querySelector('ui-counter');
await host.ready;
host.increment();

本地 Behavior 返回的 actions 发布为宿主方法；私有 state 不自动发布。每个组件最多一个顶层本地 Behavior，独立生命周期由子组件表达。

入口 HTML 的普通 DOM 不扫描 ns-*。在框架加载的组件模板中使用绑定；直接操作入口宿主时使用 property、attribute 或 addEventListener。
