createState 通过普通属性读写管理对象和数组。Signal 管理单个值与派生计算，两者使用同一套响应式机制。

创建与更新

import { createState, Signal, batch } from 'nanshann';
const state = createState({ price: 100, quantity: 2 });
const total = new Signal.Computed(() => state.price * state.quantity);
const stop = total.subscribe(value => console.log(value));

batch(() => {
  state.price = 80;
  state.quantity = 3;
});
stop();

读取建立相应依赖，写入通知受影响的订阅。batch 合并同步更新；订阅建立时会立即回调当前值。独立订阅返回释放函数，需要自行调用。

单值与派生

const count = new Signal.State(0);
const doubled = new Signal.Computed(() => count.get() * 2);
count.update(value => value + 1);
doubled.get(); // 2

Computed 是惰性、缓存的只读派生值，函数应同步且无副作用。Signal 对象使用 Object.is 比较；对象内部变化需要替换引用，或使用 createState 管理深层字段。

所有权与模板

每个组件的局部状态在 Behavior 函数内部创建。外部传入的复杂 property 保留引用，组件不应修改调用方数据。

模板不会自动解包放在 state 中的 Signal。可以通过普通 state 对象的 getter 调用 .get()，让绑定追踪读取：

return {
  state: { get count() { return count.get(); } },
  actions: { increment() { count.set(count.get() + 1); } }
};
Behavior 内优先使用 ctx.subscribe 托管订阅。直接 subscribe 的释放仍归调用方负责；移除 DOM 不会自动释放未登记的独立订阅。
