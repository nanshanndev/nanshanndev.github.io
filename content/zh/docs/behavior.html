Behavior 是同步返回 { state, actions } 的普通函数。state 管理数据，actions 提供操作；工厂本身不能返回 Promise，动作可以异步。

组件本地 Behavior

import { createState } from 'nanshann';

export default function editor(ctx) {
  const state = createState({ name: '' });
  let input;
  ctx.onMount(host => {
    input = host.shadowRoot.querySelector('input');
  });
  return { state, actions: {
    focusName() { input.focus(); },
    clear() { state.name = ''; }
  } };
}

在组件模板顶层通过唯一的可选 <script ns-behavior type="module"> 声明。每个实例调用一次工厂；普通输入更新不会重新创建它。

共享业务 Behavior

import { registerBehavior, createState } from 'nanshann';
registerBehavior('account', () => {
  const state = createState({ name: 'Ada' });
  return { state, actions: {
    rename(name) { state.name = name; }
  } };
});
<p>\{{ context.behaviors.account.state.name }}</p>

注册只登记定义，第一次消费时创建实例。同名消费者共享活动实例，最后一个消费者退出时销毁，下次消费重新创建。

在本地 Behavior 内通过 ctx.getBehavior('account') 取得并持有业务实例。业务 Behavior 不拥有 DOM，也不依赖某个消费者的路由或输入。

挂载与资源清理

ctx.onMount 同步接收宿主，通过 host.shadowRoot 查询内部节点。挂载回调必须同步；异步请求与定时器通过显式清理管理。
