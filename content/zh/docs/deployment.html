框架发行构建生成浏览器 ESM 和类型声明。应用运行使用这些发行文件与普通静态文件服务，不需要应用级 Vite 插件或模板编译。

完整部署发行文件

保留 dist 下所有文件和 chunk 相对位置。import map 将 nanshann 映射到入口。应用代码使用浏览器可执行的 JavaScript；TypeScript 转换属于自行选择的工具链。

模板与资源路径

ns-include 的 src 和外部 link 的 href 按声明模板地址解析。外部 CSS 的 url() 由浏览器按 CSS 文件地址解析。

内联 CSS 使用站点根路径、完整 URL 或 data:。内联 Behavior 通过 Blob ESM 加载，导入模块使用 import map 名称或完整 URL，不能把 ./module.js 当作模板相邻文件。

模块与 CSP

站点 CSP 必须允许 Blob 模块执行，并允许入口模块、import map、模板请求与样式资源。只有 script-src 'self' 不等于允许 Blob 模块。请在实际部署策略下验证。

Shadow DOM 不是安全沙箱。模板和 Behavior 必须来自可信应用内容，ns-html 内容由应用负责清洗。

HTTP 与错误响应

使用正确 MIME：HTML 为 text/html，JavaScript 为 text/javascript，CSS 为 text/css。缺失资源返回 404，不用入口页面掩盖错误。跨域资源遵循浏览器 CORS。

构建这个官网

npm run dev:website
# Produce static files:
npm run build:website

官网开发服务默认位于 127.0.0.1:4174。打包输出 website/dist，只复制 HTML、CSS、ES Module 和框架发行物，可部署到普通静态托管服务。
