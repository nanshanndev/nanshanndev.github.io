HTML keeps the structure; ns-* declares the connections. State changes update affected DOM nodes without re-running component Behavior.

Text, inputs and events

<p>\{{ state.name }}</p>
<input ns-model="state.name">
<button ns-bind-disabled="state.busy"
        ns-on-click="actions.save">Save</button>

Double braces interpolate text. ns-bind-* updates attributes and public inputs; ns-model connects native form controls. ns-on-* resolves a function and calls it with the native event.

Paths and expressions

Text, conditions and bindings read restricted paths such as state.user.name or properties.label. Use a getter or derived state for calculations. Event handlers may use ordinary JavaScript functions:

<button ns-on-click="event => actions.choose(event.currentTarget.value)"
        value="save">Save</button>

Conditions and keyed lists

<p ns-if="state.loading">Loading…</p>
<ul ns-else>
  <li ns-foreach="item of state.items" ns-key="item.id">
    \{{ item.label }}
  </li>
</ul>

A list source is an array. Every row needs a unique key. Matching keys preserve nodes and child component instances. Pass row data to child components through public inputs.

HTML content

ns-html inserts trusted or sanitized HTML without compiling bindings or Behavior inside it. Use ns-include when you need the component protocol.

Text and binding paths do not execute arbitrary expressions. Use ns-on-click for events; its handler must resolve to a function.
