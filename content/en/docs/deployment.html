The framework build produces browser ESM and type declarations. Applications run those distribution files through ordinary static hosting, without an application Vite plugin or template compiler.

Deploy the complete distribution

Preserve all dist files and relative chunk paths. Map nanshann to the entry with an import map. Application code is browser-executable JavaScript; TypeScript conversion is an optional toolchain choice.

Template and resource paths

ns-include src and external stylesheet link href resolve relative to their template. A stylesheet’s url() resolves relative to the CSS file itself.

Inline CSS uses root-relative paths, absolute URLs or data URLs. Inline Behavior loads as Blob ESM: import dependencies by import-map name or absolute URL, not a template-relative ./module.js.

Modules and CSP

The deployment CSP must permit Blob module execution plus entry modules, import maps, template fetches and styles. script-src 'self' alone does not permit Blob modules. Verify against your actual policy.

Shadow DOM is not a security sandbox. Templates and Behavior must be trusted application code. Applications sanitize ns-html content.

HTTP and error responses

Use correct MIME types: text/html for HTML, text/javascript for JavaScript and text/css for CSS. Missing assets return 404 rather than the entry document. Cross-origin resources follow normal CORS rules.

Run this website

npm run dev:website
# Produce static files:
npm run build:website

The local server defaults to 127.0.0.1:4174. Packaging writes website/dist by copying HTML, CSS, ES Modules and the framework distribution for ordinary static hosting.
