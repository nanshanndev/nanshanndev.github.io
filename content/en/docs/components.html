A component is a shared definition of HTML, CSS and an optional Behavior. Pages keep references; the definition owns the implementation.

Two entry points, one protocol

import { createComponent } from 'nanshann';
await createComponent('ui-counter', new URL('./counter.html', import.meta.url));
<ui-counter></ui-counter>
<ns-include src="./counter.html"></ns-include>

Tag names and HTML URLs share inputs, events, context, caching and lifecycle rules. Each reference has its own host, ShadowRoot, local state and resources.

Public inputs and private state

import { createState, property, attribute } from 'nanshann';

export default function counter(ctx) {
  const state = createState({ count: 0 });
  return { state, actions: { increment() { state.count++; } } };
}
counter.properties = { label: property('Count', { reflect: true }) };
counter.attributes = { disabled: attribute(false) };

Field declarations belong to the Behavior function and can be read before calling the factory. property() accepts JavaScript values. attribute() converts strings, booleans or finite numbers. Optional reflect connects both host interfaces.

Templates read properties.label and attributes.disabled. Behavior reads ctx.properties.label.get(). Complex input values retain their references; consume caller-owned objects without mutation and create explicit drafts when editing.

Events and content

Use native CustomEvent to emit interactions. Set bubbles: true and composed: true when an event must cross a ShadowRoot. Native slots preserve the caller’s bindings and resource ownership.

Public host actions

const host = document.querySelector('ui-counter');
await host.ready;
host.increment();

Local Behavior actions become host methods; private state is not automatically exposed. Each component has at most one top-level local Behavior. Use child components for independent lifecycles.

Ordinary entry-page DOM is not scanned for ns-* bindings. Use bindings inside framework-loaded templates. Interact with entry-page hosts through properties, attributes or addEventListener.
