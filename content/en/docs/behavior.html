Behavior is an ordinary synchronous function returning { state, actions }. State holds data and actions provide operations. The factory cannot return a Promise; actions may be asynchronous.

Local component Behavior

import { createState } from 'nanshann';

export default function editor(ctx) {
  const state = createState({ name: '' });
  let input;
  ctx.onMount(host => {
    input = host.shadowRoot.querySelector('input');
  });
  return { state, actions: {
    focusName() { input.focus(); },
    clear() { state.name = ''; }
  } };
}

Declare it through a single optional top-level <script ns-behavior type="module"> in the component template. Each instance calls the factory once. Ordinary input updates preserve that instance.

Shared business Behavior

import { registerBehavior, createState } from 'nanshann';
registerBehavior('account', () => {
  const state = createState({ name: 'Ada' });
  return { state, actions: {
    rename(name) { state.name = name; }
  } };
});
<p>\{{ context.behaviors.account.state.name }}</p>

Registration stores a definition. The first consumer creates the instance. Consumers of the same name share its active instance, which is destroyed when the last consumer leaves and recreated on later use.

A local Behavior can use ctx.getBehavior('account') to acquire and hold it. Business Behavior has no DOM and does not inherit a consumer’s route or inputs.

Mounting and cleanup

ctx.onMount receives the host synchronously. Query internal nodes with host.shadowRoot. Mount callbacks must stay synchronous. Explicitly register cleanup for requests and timers.

const controller = new AbortController();
ctx.onDispose(() => controller.abort());
// Pass controller.signal to your application request.
ctx has no parent. Connect components through public inputs, events and host actions. Asynchronous actions are not automatically cancelled; applications manage cancellation and stale results.
